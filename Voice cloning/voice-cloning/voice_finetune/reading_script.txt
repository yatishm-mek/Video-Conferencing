# Reading script for fine-tuning the voice (Qwen3-TTS 1.7B).
# General, everyday speech: conversation, stories, explanations, questions, numbers,
# names, emotions and longer reading-style sentences, so the voice works for anything.
# Lines starting with # are notes and are not read.
#
# How to record:
#  - Quiet room, same microphone, same distance (about a hand's width from your mouth).
#  - Speak in your normal, natural voice, as if talking to a person, not reading.
#  - Pause about one second after every sentence.
#  - Made a mistake? Just pause, and read the whole sentence again. Bad pieces are dropped.
#  - One session = one recording file (about 5 minutes). Take a break between sessions,
#    drink water. Record a session again whenever it doesn't feel right.
#  - Save the files in data\voice_dataset\recordings (any name, .wav or .m4a).
